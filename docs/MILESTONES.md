# 마일스톤 — M1 웹·광고 · M2 서버 저장·로그인 · M3 앱 연동

무엇을 지금 만들고 무엇을 나중으로 미루는지의 기준. 방향이 여러 번 바뀌었고, 그때마다 만든 것을
버리기보다 **어느 마일스톤의 것인지** 정하는 편이 낫습니다. 이 문서가 그 기준입니다.

**세 마일스톤은 병렬로 진행합니다.** 순서가 아니라 묶음입니다 — 무엇이 어디에 속하는지를 정할 뿐,
하나가 끝나야 다음이 시작하지는 않습니다. M1이 소유자 쪽 정보를 기다리는 동안 M2·M3의 코드가 멈춰
있을 이유가 없습니다.

병렬로 가되 두 가지는 지킵니다.

1. **출시 순서는 여전히 M1 → M2 → M3입니다.** 만드는 것과 내보내는 것은 다릅니다. M2를 먼저 배포하면
   처리방침이 서버 보관까지 설명해야 하고, M1이 필요로 하지 않던 결정(가격·보관 기간)이 M1의 발목을
   잡습니다
2. **각 마일스톤은 자기 브랜치와 자기 PR을 씁니다.** 한 PR에 두 마일스톤이 섞이면 하나가 막힐 때
   나머지도 같이 막힙니다

## M1 — 웹 전용, 광고 · **지금 여기**

**한 문장:** 정적 사이트 하나로 100문항을 읽고 답하고, 상대와 비교하고, 결과를 메일로 보내고,
그 페이지에 광고가 붙는다.

### 규칙

- 서버 없음. 답은 **읽는 사람의 브라우저에만** 저장됩니다
- 계정 없음. 가입도 로그인도 없습니다
- 앱 없음. 사이트가 앱을 가리키지 않습니다
- 답이 브라우저를 떠나는 순간은 **사용자가 직접 링크나 메일을 보낼 때뿐**입니다

### 들어간 것

| | 상태 |
|---|---|
| 결혼 100제, 10개 파트, 정적 페이지 | ✅ 배포됨 |
| 답 저장 (브라우저), 결과지, 지우기 | ✅ 배포됨 |
| 문항별 메모(중요도·이유·상대 추측) | ✅ 배포됨 · 대화 블록은 소유자 요청으로 제거 |
| 링크로 상대와 비교 (URL 조각, 서버 경유 없음) | ✅ 배포됨 |
| 초대 버튼 (`navigator.share` · 클립보드) | ✅ 배포됨 · 함께 풀기 패널로 확장 |
| 결과를 메일로 (`mailto:`, 전송 없음) | ✅ 배포됨 |
| 애드센스 (id 두 개로 켜짐) + `ads.txt` | ✅ 코드는 배포됨 · id 두 개 대기 (N5b) |
| 소개 · 문의 페이지 | ✅ 배포됨 |
| **개인정보 처리방침** | ✅ `/privacy/` 게시 — 사업자 정보 채워짐 |
| Search Console · 네이버 서치어드바이저 등록 | ⏳ 코드 쪽은 준비됨 — `SITE.verification` 토큰 두 줄(2026-09-02). 등록은 소유자 |

### 끝났다고 말할 수 있는 조건

1. 처리방침이 게시되어 있고, **브라우저 저장과 광고 쿠키를 둘 다** 설명한다
2. 애드센스 심사를 통과하고 실제 광고가 나온다
3. 두 사람이 링크만으로 비교하고 결과를 메일로 받는 것이 실제 기기에서 된다

### 막고 있던 것 — 풀렸습니다

**처리방침이 게시되었습니다.** 상호 `afterscent`, 대표자 `Jeongsu Lim`(개인정보 보호책임자 겸함),
주소 `서울특별시 구로구 개봉동 481`, 문의 메일 `studio@afterscent.kr` — 제30조가 요구하는 항목이
다 찼고, `/privacy/`가 빌드되어 푸터와 사이트맵에 붙어 있습니다.

사업자등록번호와 통신판매업 신고번호는 아직 비어 있습니다. 둘 다 있으면 표시되고 없으면 생략되는
선택 항목이라 게시를 막지 않습니다.

**이제 남은 것은 애드센스 심사입니다** — 게시된 처리방침이 그 전제였고, 지금은 신청할 수 있습니다.
심사를 통과하면 `SITE.adsenseClient`와 `adsenseSlot` 두 줄로 광고가 켜집니다.

### 마무리 점검 (2026-09-02)

| 조건 | 상태 | 근거 |
|---|---|---|
| 1. 처리방침이 브라우저 저장과 광고 쿠키를 둘 다 설명 | ✅ 게시됨 · 광고 쿠키 절은 `adsenseClient`가 채워지는 순간 바뀜 | `site/pages.js` privacyCopy 「쿠키와 광고」, `test/site.test.js` |
| 2. 애드센스 심사 통과, 실제 광고 | 🔴 **소유자** — 신청 절차는 `docs/OWNER_ACTIONS.md` N5b | 코드는 배포됨 |
| 3. 두 사람이 링크만으로 비교, 결과를 메일로 | ✅ 헤드리스 크롬으로 끝까지 확인(2026-09-02): A가 3문항 답하고 임시 저장 → 링크 생성(153자, `#c=` 조각) → 별도 브라우저의 B가 자기 답 3개를 저장한 뒤 A의 링크를 열면 비교 패널이 열리고 "두 사람 모두 답한 질문 3, 다르게 고른 질문 1"을 표시 → B의 메일 링크가 두 사람의 답을 본문에 담은 `mailto:`. **실제 기기(카카오톡으로 링크 전달 → 상대 휴대전화)에서의 한 번은 소유자 확인** | `scratchpad/m1-e2e.mjs` 실행 기록 |
| 서치콘솔 · 네이버 등록 | 🟢 **소유자** — 토큰 두 줄 자리 준비됨(`SITE.verification`), 절차는 X5e·X5f | `site/seo.js` verificationTags |

M1에서 코드로 할 일은 더 없습니다. 남은 셋(애드센스 신청, 서치콘솔, 네이버)은 전부 소유자의 계정에서
하는 일이고, 각각 `site/config.js`에 토큰 한 줄을 넣는 것으로 사이트에 반영됩니다.

## M2 — 서버 저장, 로그인

**한 문장:** 계정이 생기고, 답이 서버에 남고, 두 사람이 링크를 주고받지 않아도 같은 화면을 본다.

### M1과 무엇이 달라지는가

| | M1 | M2 |
|---|---|---|
| 답이 있는 곳 | 브라우저 | 서버 |
| 기기 바꾸면 | 사라짐 | 이어짐 |
| 비교 | 링크를 손으로 전달 | 초대 → 워크스페이스 |
| 결과 메일 | `mailto:` (앱을 열어줌) | 서버가 발송 (Resend) |
| 처리방침 | 브라우저 저장 + 광고 쿠키 | **+ 서버 보관, 보관 기간, 동의, 파기** |

### 이미 만들어져 있는 것

M2의 서버 쪽은 **대부분 존재하고 동작이 확인됐습니다.** 계정(매직링크·소셜), 워크스페이스,
초대·수락, "두 사람 다 제출해야 공개", 합의안, 계정 삭제, 감사 로그가 서버에 있습니다.

100제를 그 흐름에 올리는 작업도 한 번 완성해서 브라우저로 끝까지 확인했고, 방향이 바뀌어 되돌렸습니다.
**닫힌 PR #71의 diff가 그것입니다.** M2를 시작할 때 그 두 커밋을 다시 적용하는 것이 출발점입니다.

### 시작 전에 정해야 하는 것

1. **가격** — 100제가 무료인지 유료인지. 12문항 팩에 있던 결제 구조를 어떻게 할지
2. **보관 기간** — 답을 언제까지 들고 있을지. "탈퇴하면 즉시"인지 별도 기간이 있는지
3. **동의 시점** — 어느 화면에서 무엇에 동의받을지
4. **정적 사이트의 역할** — 무료 읽기·검색 유입 표면으로 남길지, 전부 로그인 뒤로 넣을지

M1의 처리방침은 M2에서 **다시 써야 합니다.** 브라우저에만 있던 것이 서버로 가면 고지 대상이 달라집니다.

## M3 — 앱 연동

**한 문장:** 같은 계정과 같은 워크스페이스를 네이티브 앱에서도 연다.

### 이미 만들어져 있는 것

Expo 앱이 있고, 아이콘·스플래시·폰트가 붙어 있고, 매직링크·초대·팩 화면의 네이티브 흐름이
테스트로 덮여 있습니다. `loveme://` 스킴 전환과 앱 설치 랜딩(`/install`)도 코드로 남아 있습니다
(웹의 주 동선에서만 빠졌습니다).

### 필요한 것

- 애플 개발자 등록(개인) · 구글 플레이 등록 — 대기 시간이 가장 긴 항목
- 카카오 개발자 앱 (리다이렉트 URI)
- 스토어 심사 — 앱은 처리방침 URL을 요구하므로 M1의 결과물이 여기서 다시 쓰입니다
- 웹의 앱 전환 재도입: `AB_WEB_CONSUME_FALLBACK`, 설치 배너

### 왜 출시는 마지막인가

스토어 심사는 며칠에서 몇 주가 걸리고 우리가 통제할 수 없습니다. 다만 **등록과 대기는 지금 시작하는
편이 낫습니다** — 애플 개인 등록과 카카오 앱 등록은 M1·M2의 답을 몰라도 할 수 있고, 그 대기 시간이
가장 긴 항목이기 때문입니다. 심사에 올리는 빌드만 M1·M2가 정해진 뒤로 미룹니다.
